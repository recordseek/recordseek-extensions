2. Purpose and audience
RecordSeek is a free tool for family historians and genealogists. When you find a record online (a census page, an obituary, a book or a newspaper article), adding it as a properly cited source in your FamilySearch or Ancestry family tree usually means copying the title, address and details by hand. RecordSeek does that in one click. It reads the page you're viewing and opens a citation form with the title, URL, any selected text and, on supported genealogy sites, the person and event details already filled in.

The macOS app is the container for the RecordSeek Safari Web Extension. Opening the app shows how to turn the extension on in Safari. The extension adds a RecordSeek toolbar button and right-click menu item.

3. How to use it
1. Open RecordSeek and click "Quit and Open Safari Settings…" (or go to Safari → Settings → Extensions).
2. Tick RecordSeek. When Safari asks, allow it on recordseek.com and familysearch.org.
3. Visit any web page, for example a record on https://www.familysearch.org or any news or Wikipedia article.
4. Click the RecordSeek button in the Safari toolbar, or right-click the page and choose RecordSeek.
5. A RecordSeek window opens with the citation details filled in.
No login is needed to use the extension or to see the citation details. Saving the citation into a family tree uses the reviewer's own free FamilySearch account, which you sign in to on FamilySearch's own page. RecordSeek never sees the password.

4. External services
- RecordSeek.com (our website): shows the citation form.
- FamilySearch (FamilySearch International): its official API and OAuth sign-in save the citation to the user's FamilySearch tree.
- Ancestry: users can open their Ancestry tree to attach the citation.
- genscrape: an open-source library (MIT) bundled in the app that reads record details on genealogy pages.
No payment processors, ads, tracking SDKs or AI services are used.

5. Regional differences
RecordSeek works the same in every region. There are no region-specific features or content.

6. Regulated industry / third-party material
RecordSeek isn't in a regulated industry. It doesn't host or redistribute third-party records. It creates a citation (title, link and details) for a page the user is already viewing, and saves it to the user's own tree through FamilySearch's public developer API. RecordSeek is a registered FamilySearch developer application.
