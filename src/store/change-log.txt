| 2.6.1   |
+---------+

* Least-privilege permissions: RecordSeek now runs on a page only when you click it (activeTab). It no longer reads every site you visit.
* Host access is limited to recordseek.com and familysearch.org. Removed the "tabs" permission and web-accessible resources.
* genscrape is bundled unminified, so reviewers can read it, and parses HTML without innerHTML.

+---------+
| 2.6.0   |
+---------+

* Rebuilt every package as a Manifest V3 extension so it can go back in the stores.
* Safari is a Web Extension. Its share window is 700px wide so the FamilySearch and Ancestry actions stay visible on current macOS.
* Added Brave, Arc, Naver Whale, Samsung Internet, Orion, and Chromium packages. Vivaldi and Yandex now build the RecordSeek extension instead of the old sidecar stub.
